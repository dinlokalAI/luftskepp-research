# Luftskepp Research – Dokumentation

Se även:
- [CLI_AND_CRON.md](CLI_AND_CRON.md) – CLI-användning och cron

## Snabbstart

```bash
python scripts/init_db.py
python scripts/cli.py status
python scripts/cli.py terms list
python scripts/cli.py terms expand luftskepp
```

Fullständig CLI och MCP-server finns i den lokala zip-filen / artifacts. Kopiera `scripts/cli.py` och `scripts/mcp_server.py` hit för komplett funktionalitet.
